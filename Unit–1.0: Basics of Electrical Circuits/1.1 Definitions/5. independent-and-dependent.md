# Independent and Dependent Sources

## 1. Independent Source

An **independent source** is an electrical source whose voltage or current does not depend on any other voltage or current in the circuit.

### Examples

- Independent Voltage Source
- Independent Current Source

---

## 2. Dependent Source

A **dependent source** is an electrical source whose voltage or current depends on another voltage or current present in the circuit.

### Examples

- Voltage Controlled Voltage Source (VCVS)
- Voltage Controlled Current Source (VCCS)
- Current Controlled Voltage Source (CCVS)
- Current Controlled Current Source (CCCS)

## Difference Between Independent and Dependent Sources

| Independent Source | Dependent Source |
|---|---|
| Does not depend on another circuit variable. | Depends on another voltage or current in the circuit. |
| Its value is specified independently. | Its value is controlled by another circuit variable. |
| Uses a circular source symbol. | Uses a diamond-shaped source symbol. |
| Examples: Independent Voltage Source, Independent Current Source | Examples: VCVS, VCCS, CCVS, CCCS |

---

## Quick Revision

**Independent Source → Does not depend on another circuit variable**

**Dependent Source → Depends on another circuit variable**

### Dependent Source Types

**VCVS → Voltage Controlled Voltage Source**

**VCCS → Voltage Controlled Current Source**

**CCVS → Current Controlled Voltage Source**

**CCCS → Current Controlled Current Source**
