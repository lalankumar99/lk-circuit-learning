# Unilateral and Bilateral Components

## 1. Unilateral Component

A **unilateral component** is an electrical component whose behavior or current flow depends on the direction of the applied voltage or current.

It mainly allows current to flow in **one direction** and restricts or blocks current in the opposite direction.

### Basic Concept

**Forward Direction → Component → Current Allowed**

**Reverse Direction → Component → Current Blocked**

![Unilateral Component](https://lalankumar99.github.io/lk-circuit-learning/Icons/Diagram/unilateral.png)

### Key Points

- Allows current mainly in one direction.
- Its behavior changes when the direction of voltage or current is reversed.
- It can block or strongly restrict current in the opposite direction.
- Its V-I characteristic is generally different for opposite directions.

### Example

- Diode

---

## 2. Bilateral Component

A **bilateral component** is an electrical component whose behavior is substantially the same when the direction of voltage or current is reversed.

It allows current flow in **both directions**, subject to the component's electrical characteristics.

### Basic Concept

**Forward Direction → Component → Current Flow**

**Reverse Direction → Component → Current Flow**

![Bilateral Component](https://lalankumar99.github.io/lk-circuit-learning/Icons/Diagram/bialetral.png)

### Key Points

- Allows current flow in both directions.
- Its electrical behavior remains substantially the same when the direction is reversed.
- The V-I characteristic is generally symmetrical for opposite directions in ideal bilateral components.
- Commonly used in circuits where current direction is not restricted.

### Examples

- Resistor
- Capacitor
- Inductor
- Transformer

---

## Difference Between Unilateral and Bilateral Components

| Unilateral Component | Bilateral Component |
|---|---|
| Allows current mainly in one direction. | Allows current in both directions. |
| Behavior depends strongly on direction. | Behavior is substantially similar in both directions. |
| V-I characteristic is generally different for opposite directions. | V-I characteristic is generally symmetrical for opposite directions. |
| Used for rectification and one-way current control. | Used for resistance, energy storage, and magnetic coupling. |
| Example: Diode | Examples: Resistor, Capacitor, Inductor |

---

## Quick Revision

**Unilateral → Current mainly in one direction → Example: Diode**

**Bilateral → Current can flow in both directions → Examples: R, C, L**
