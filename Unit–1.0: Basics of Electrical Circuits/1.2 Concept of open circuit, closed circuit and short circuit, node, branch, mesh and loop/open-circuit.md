# Open Circuit

An **open circuit** is an electrical circuit in which the conducting path is broken or incomplete.

Because the path is broken, **current cannot flow through the circuit**.

### Basic Concept

**Broken Path → No Current Flow**

![Open Circuit](https://lalankumar99.github.io/lk-circuit-learning/Icons/Diagram/open-circuit.png)

### Example

A circuit with an **open switch** is an example of an open circuit.

When the switch is open, the circuit path is broken and current does not flow.

### Key Points

- The conducting path is incomplete.
- Current does not flow through the circuit.
- An open switch can create an open circuit.
- The resistance of an ideal open circuit is considered infinite.

### Quick Revision

**Open Circuit → Broken Path → No Current Flow → Infinite Resistance (Ideal)**
